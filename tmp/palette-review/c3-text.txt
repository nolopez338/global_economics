Evaluated criterion

C3: Models binary economic outcomes with Bernoulli random variables, interpreting success and failure in contexts such
as default, gain, loss, or claim occurrence.

How to practise. Attempt each C3 task before opening its linked worked solution. Use the return arrows for the
contents, the problem, and its problem list. All data are hypothetical teaching models. Keep exact expressions where
useful; use exact break-even probabilities and decimals only as approximations. Monetary amounts are in USD. Each
monetary variable has one strictly positive and one strictly negative payoff. Analyse the sign of each expected value
separately, using its own zero threshold. All variables in a problem are functions of the same X; separate analyses do not
imply statistical independence.

1.1   Introductory example 1: clothing inventory

Observe one shop’s demand over one weekend. Let E be high demand and E c low demand. Define X = 1 on E
and X = 0 on E c , with p = P (E) = 0.4 and 1 − p = 0.6 . The indicator is unitless. A small order gives
f1 (0) = −20 , f1 (1) = 60 USD; a large order gives f2 (0) = −40 , f2 (1) = 120 USD. Both monetary variables use
this same X:
                              Y1 = f1 (0) + [f1 (1) − f1 (0)]X = −20 + 80X USD,
                                 Y2 = f2 (0) + [f2 (1) − f2 (0)]X = −40 + 160X    USD.
For i = 1, 2, {Yi < 0} = {X = 0} = E c has probability 1 − p, initially 0.6. Their supports are {−20, 60} and {−40, 120}
USD; each puts mass 0.6 on its negative value and 0.4 on its positive value. Each CDF is 0 below its negative value, 0.6
from that value up to (excluding) its positive value, and 1 from its positive value onward.

1.3   Binary models and distributions

One observation in a stated period gives two mutually exclusive and exhaustive states. Write X ∼ Bernoulli(p), 0 ≤ p ≤ 1.
The support is a set of numerical values with positive probability:
                                                                    
                                                                    
                                                                    
                                                                    {0, 1}, 0 < p < 1,
                                                                    
                                 SX = {x ∈ R : P (X = x) > 0} = {0},         p = 0,
                                                                    
                                                                    
                                                                    {1},
                                                                    
                                                                             p = 1.

For a monetary consequence, SY = {y ∈ R : P (Y = y) > 0}. An event such as {Yi < 0} is a condition on the observation;
it is not a support. These discrete variables have probability mass functions (PMFs), not ordinary probability density
functions. Their cumulative distribution functions (CDFs) add masses up to and including a threshold. No separate
density is required. All monetary variables in a problem share the same indicator X. Analysing them separately does not
make them statistically independent. Strictly positive and negative describe monetary payoffs, not E or the labels 0 and 1.

Task 1 — Establish the binary model and monetary transformations.

  1. Identify one observation, its period, the two states and event E. Define its complement E c , and X = 1 on E, X = 0
     on E c ; use this same X for every monetary variable.
  2. State p = P (X = 1) and 1 − p = P (X = 0). Give SX in set-builder notation and evaluate it. Use direct masses at
     p = 0, 1, avoiding 00 .

     fi (1) = yi1 and Yi = fi (0) + [fi (1) − fi (0)]X = yi0 + (yi1 − yi0 )X. Require yi0 yi1 < 0: one strictly positive and one

Task 2 — Analyse the sign of each expected value separately.

  1. For one Yi at a time, hold its two state payoffs fixed and vary only p ∈ [0, 1].
  2. Derive E [ Yi ] = p fi (1) + ( 1 − p ) fi (0) = fi (0) + [fi (1) − fi (0)]p, in USD.
  3. Solve E [ Yi ] = 0 exactly:

  4. Solve E [ Yi ] > 0 and E [ Yi ] < 0 separately. If fi (1) > fi (0), gain occurs on (p∗i , 1] and loss on [0, p∗i ). If
     fi (1) < fi (0), gain occurs on [0, p∗i ) and loss on (p∗i , 1]. In both cases, equality holds only at p∗i ; include the applicable

  5. Interpret positive expectation as expected net gain , negative expectation as expected net loss , and zero as

Closing reminders: Bernoulli modelling and individual break-even analysis

Define one event E, its complement E c , and keep X = 1 on E, X = 0 on E c . The indicator is unitless; p = P (E). Each
Yi = fi (X) is in USD, with one strictly positive and one strictly negative monetary payoff. These signs refer to money,
not to the event or its indicator. Show both state mappings and Yi = fi (0) + [fi (1) − fi (0)]X. Use supports with positive
probability; omit zero-mass values at p = 0, 1. Distinguish the transformation, PMF and CDF; sort amounts numerically
for CDFs. For each Yi separately, keep both payoffs fixed, vary only p ∈ [0, 1], derive its expectation , solve its own zero
equation and both strict inequalities, and include the applicable interval endpoints. Positive expectation is expected
net gain, negative is expected net loss and zero is break-even. Evaluate the initial probability and provide a separate
labelled graph with the zero line and exact root. Separate analyses do not imply independence: all variables share X. An
 expected value is a long-run average, not a guarantee of realized profit.

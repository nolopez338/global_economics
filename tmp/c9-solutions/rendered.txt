Models and simplifying approximation (all pages). Each question supplies a continuous model for a signed
deviation. Compare XT = m+aT , T ∼ tν , with XN = m+aZ, Z ∼ N (0, 1), using the same location m and scale a > 0.
Here ν = n − 1 , where n is the number of observations in the sample. For simplicity, use the stated “approximate
                                                                                                        q

standard deviation” directly as a. This is a teaching approximation: Var(XT ) = a2 ν−2 and SD(XT ) = a ν−2    for
ν > 2, whereas Var(XN ) = a2 . The approximation is coarser for small ν and improves as ν increases. Use the supplied
models without adjusting a. Negative deviations mean below the reference; positive deviations mean above it.
Reference-table method. Use the supplied normal CDF table and Student’s t critical-value table. In row ν and
column α, P (T > t∗ ) = α; by symmetry, P (T < −t∗ ) = α. Standardize using c = (x − m)/a for either model;
back-transform using x = m + ac. Read t∗ to three decimals. Direct bounds retain enough digits to recover the
intended t entries. For normal direct probabilities, round c to two decimals before lookup. For normal inverse problems,
choose the closest CDF entry.

Solutions
Use the supplied approximation XT = m + aT , T ∼ tν , and XN = m + aZ, with ν = n − 1: the stated a is used
directly as the scale. Write Fν (c) = P (T < c) and Φ(c) = P (Z < c). Since both models are continuous, including or
excluding an endpoint does not change a probability.
Read positive t critical values to three decimals from the row for ν and right-tail column α: the entry t∗ means
P (T > t∗ ) = α. These printed critical values approximate the underlying distribution. In the calculations below, the
associated table probabilities are used as the working values. Equalities in subsequent arithmetic are exact for those
selected table values; the resulting model probabilities and cutoffs remain approximations.
For direct normal calculations, first round each standardized boundary to two decimals, then read the CDF to four
decimals. For inverse normal calculations, choose the closest printed CDF entry. At cumulative targets 0.0500 and
0.9500, the printed entries at magnitudes 1.64 and 1.65 are equally close: consistently choose |z| = 1.64. Thus
Φ(1.64) = 0.9495 is used for a 0.9500 target, and Φ(−1.64) = 1 − 0.9495 = 0.0505 for a 0.0500 target.
Comparison errors measure differences between the two model results, not errors against observed truth. Use displayed
table probabilities for direct errors and unrounded back-transformed cutoffs for inverse errors. Keep absolute values in
percentage denominators; a zero denominator would make that percentage undefined. Report probabilities and their
absolute differences to four decimals, contextual cutoffs and their absolute differences to two decimals with units, and
percentage errors to two decimals.

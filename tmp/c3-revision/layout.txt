Evaluated criterion

C3: Models binary economic outcomes with Bernoulli random variables, interpreting success and failure in contexts such
as default, gain, loss, or claim occurrence.

How to practise. Attempt each C3 task before opening its linked worked solution. Use the return arrows for the
contents, the problem, and its problem list. All data are hypothetical teaching models. Keep exact expressions where
useful; use exact thresholds for decisions and decimals only as approximations. Monetary amounts are in USD. All
decisions maximize expected net profit; negative payoffs are net losses.

1.1   Introductory example 1: clothing inventory

Observe one shop’s demand over one weekend. Let E be high demand and define X = 1 for E, X = 0 for
low demand. These are the only two states in this simplified model. With p = 0.4 , low demand has probability
 1 − p = 0.6 . The indicator has no units; it does not measure sales or profit.

First write Y = f ( X ). For a small stock order, f (0) = 20 and f (1) = 60 USD, so Y = f ( X ) = 20 + 40 X
USD. A larger order has f2 (0) = −20, f2 (1) = 120, hence Y2 = f2 (X) = −20 + 140X USD; call the small order A1 and
Y1 = Y . The monetary loss event {Y2 < 0} = {X = 0} has probability 0.6. Task 1 describes these distributions. Task 2
holds both payoff rules fixed: E[Y1 ] = 20 + 40p and E[Y2 ] = −20 + 140p USD. They tie at p = 2/5; the small order is
preferred below this threshold and the larger order above it. At the stated p = 0.4, both have expected profit 36 USD.


1.2   Introductory example 2: coffee-shop disruption

Observe one coffee shop over one day. Let E be an equipment disruption: X = 1 if it occurs and X = 0 otherwise.
Suppose p = 0.1 and 1 − p = 0.9 . Mathematical success can be financially undesirable. Without backup, the
monetary consequence is Y1 = f1 ( X ), where f1 (0) = 100 and f1 (1) = −20 USD: Y1 = f1 (X) = 100 − 120X USD.
A backup contract gives Y2 = f2 (X) = 60 USD in either state. Thus SY1 = {y ∈ R : P (Y1 = y) > 0} = {−20, 100},
whereas SY2 = {y ∈ R : P (Y2 = y) > 0} = {60}. Both state masses combine at 60 USD for Y2 . The CDF for Y1 jumps by
0.1 at −20 and by 0.9 at 100: order money numerically, not by the labels of X. Expected profits are 100 − 120p and 60
USD, tying at p = 1/3. At p = 0.1 choose no backup (88 versus 60 USD); above 1/3 choose backup.


1.3   Binary models and distributions

One observation in a stated period gives two mutually exclusive and exhaustive states. Write X ∼ Bernoulli(p), 0 ≤ p ≤ 1.
The support is a set of numerical values with positive probability:
                                                                    
                                                                    
                                                                    
                                                                    {0, 1}, 0 < p < 1,
                                                                    
                                 SX = {x ∈ R : P (X = x) > 0} = {0},         p = 0,
                                                                    
                                                                    
                                                                    {1},
                                                                    
                                                                             p = 1.

For a monetary consequence, SY = {y ∈ R : P (Y = y) > 0}. An event such as {Yi < 0} is a condition on the observation;
it is not a support. These discrete variables have probability mass functions (PMFs), not ordinary probability density
functions. Their cumulative distribution functions (CDFs) add masses up to and including a threshold. No separate
density is required. One Bernoulli observation requires no independence assumption across trials.

Task 2 — Perform sensitivity analysis on p and make a decision.

  1. Keep the same two states and fixed monetary rules; vary only p ∈ [0, 1]. Calculate and simplify E[Yi ] = pfi (1) +
     (1 − p)fi (0).
  2. Construct an extended payoff table and graph expected monetary value against p. Each line joins fi (0) at p = 0 to
     fi (1) at p = 1.
  3. Solve every pairwise equality exactly. Discard intersections outside [0, 1] for decisions; within the interval compare
     all lines, since an intersection below the greatest expected value does not change the preferred alternative.
  4. State the maximizing decision on every interval, including endpoints and optimal ties. Interpret slopes, thresholds
     and the recommendation at the given p.

Closing reminders: Bernoulli modelling and economic decisions

Define one event E and keep X = 1 on E throughout both tasks. The indicator is unitless; the monetary consequence
is Y = f (X), or Yi = fi (X) in USD for alternative Ai . Do not confuse the transformation fi with a PMF or CDF.
Use set-builder supports with positive probability, omit zero-mass values, and combine equal monetary outcomes. Sort
amounts numerically before writing CDFs. Keep the state payoffs fixed during sensitivity analysis. Maximize expected
net profit, use exact decision thresholds, compare every alternative at an intersection, and include p = 0, 1 and optimal
ties. A high expected value is an average-based decision criterion, not a guarantee of the realized profit.

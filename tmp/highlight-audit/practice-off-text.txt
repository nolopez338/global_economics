2.2 Practice procedure
Reasoning chain: complete outcomes and probabilities → variable definition and units → mappings → support →
PMF → validity checks → requested probability and contextual interpretation.
Task 1. Identify the outcomes and their probabilities. List all complete outcomes. Read supplied probabilities,
or list ordered decisions and multiply the component probabilities within each independent outcome. For a supplied
PMF, identify the observed categories or counts. Recover any missing outcome probability by making the total 1.
Task 2. Define variables and units; map, list support, build and check PMFs. Define each discrete variable
and its units. Map each outcome to a value and list the distinct values with positive mass as the support. Keep one row
per complete outcome in your mapping. To build the PMF, use one entry per distinct supported value and add the
probabilities of mutually exclusive outcomes that give that value. Check that the masses are non-negative and total 1.
Task 3. Find and interpret a requested probability. Write the event in terms of the specified variable, paying
attention to endpoints. Use the PMF to find its probability, keep intermediate values exact, and interpret the result in
context.

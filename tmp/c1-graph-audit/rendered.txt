1     Introduction

All data in this activity are hypothetical teaching models. Probabilities have no monetary units. Keep exact expressions

1.1   From a school sale to a number

A school enterprise offers a notebook to each of three visitors. Each visitor either buys (B) or does not buy (N). An
outcome records the whole story, such as BNN: the first visitor buys, while the second and third do not. A random
variable assigns a number to every outcome.

The experiment has eight possible outcomes:

                                Ω = {NNN, BNN, NBN, NNB, BBN, BNB, NBB, BBB}.


Consider three random variables defined on this experiment:

• Example 1 (Number of buyers). Let X be the number of visitors who buy a notebook. Then X (BNN) = 1,
  X (BBN) = 2, X (BBB) = 3, and X (NNN) = 0.

• Example 2 (Sales revenue). If each notebook costs $5, let Y be the total revenue. Then Y (BNN) = 5,
  Y (BBN) = 10, Y (BBB) = 15, and Y (NNN) = 0.

• Example 3 (First visitor’s purchase). Let Z equal 1 if the first visitor buys a notebook and 0 otherwise. Then
  Z (BNN) = 1, Z (BBN) = 1, Z (BBB) = 1, and Z (NBN) = 0.

while a lowercase letter such as x represents a possible or observed numerical value.

Suggested answer: No; they describe different visitors buying. Both give X = 1 and Y = 5, but Z (BNN) = 1 whereas

1.2    Support, measurements and units

The support of a random variable is the set of values with positive probability. Different random variables describing
the same experiment may have different supports and measurement units.

Consider the three random variables introduced previously:

• Example 1 (Number of buyers). The support of X is {0, 1, 2, 3}, measured in buyers. The values represent zero,
  one, two, or three visitors purchasing a notebook.

• Example 2 (Sales revenue). The support of Y is {0, 5, 10, 15}, measured in dollars. Revenue increases in
  increments of $5 because each notebook has a fixed price.

• Example 3 (First visitor’s purchase). The support of Z is {0, 1}, with no physical unit. The values indicate
  whether the first visitor buys (1) or does not buy (0).

Braces denote a set of possible values. All three examples have discrete supports because their values can be listed
individually. A discrete support may be finite, such as {0, 1, 2, 3}, or countably infinite, such as {1, 2, 3, . . .}, where the
dots indicate that the pattern continues indefinitely.

A continuous random variable, by contrast, can take values throughout an interval. For example, the exact time required
to complete a purchase may be modelled as continuous and measured in seconds. If times are rounded to whole seconds,
the recorded values become discrete.

Check. Can X = 1.6, Y = 7, or Z = 2? Explain.

Suggested answer: No. The buyer count X must be an integer between 0 and 3; revenue Y can only be 0, 5, 10, or 15
dollars; and the indicator Z can only be 0 or 1.


1.3    Assign probability to each value

The probability mass function (PMF) assigns a probability to each value of a discrete random variable. For X , it
is written pX (x) = P (X = x), read “the probability that X equals x”. The subscript identifies the random variable:
pY (y) = P (Y = y) describes revenue, while pZ (z) = P (Z = z) describes the first visitor’s purchase indicator.

Every probability must be non-negative, and the probabilities over the support must add to 1. A value outside the
support has probability zero. To find the probability of a value, add the probabilities of all outcomes that produce it;
different outcomes need not be equally likely.

                                     X

must still be non-negative. An infinite list of possible values can therefore have a finite total probability of 1; the next
problems show how to check both finite and infinite models.

7                     Closing reference: key ideas and common errors

An outcome is a whole story; a random variable maps it to a number. Group outcomes before assigning masses.
Support contains only positive-mass values. Discrete does not mean equally likely, and a monetary variable need not be
continuous. Check every mass and the total; never confuse a number of outcomes with a probability.

Permutations and Combinations I Introduction: Counting Choices Multiplication principle. Count a process one step at a time. If the number of available choices at each step is the same for every possible sequence of earlier choices, multiply these numbers to count the complete outcomes. Order matters means that exchanging positions changes the outcome. Notation and when to use it. Let n be the total number of objects, a nonnegative integer, and let r be the number selected, an integer with 0 ≤ r ≤ n. • To arrange all n distinct objects in a row, there are n choices for the first position, then n − 1, and so on. Their product is called factorial : n! = n(n − 1) · · · 2 · 1 for n ≥ 1. By convention, 0! = 1: there is one empty arrangement. • To fill r ordered positions with distinct objects chosen from n without replacement, the choices decrease n! ; each object can be used at most once. from n to n − r + 1. The count is (n − r)! • To choose r distinct objects when   order does not matter, divide the ordered count by the r! orders of each n n! selected group. All seven runners appear once; order matters because the photograph has a left and a right. First enforce the required adjacency. Replace P, Q by a single block. We now arrange six distinct units: the block and the other five runners. The block has two internal orders, P Q and QP .

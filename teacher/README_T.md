# Directory Summary

## Purpose

Provides teacher-facing timetables and supporting academic-calendar, class-detail, presentation, schedule-authoring, and assessment-results tools.

## Files

| File | Type | Purpose |
|---|---|---|
| [`schedule-teacher.html`](schedule-teacher.html) | HTML | Displays the six-cycle-day teacher timetable, class navigation, Class View and Calendar View links, and additional Full Schedule, Magis, and external weekly-document cards. |
| [`schedule.html`](schedule.html) | HTML | Displays the standard six-cycle-day weekly timetable with timed activities, class and resource links, Class View, Calendar View, and a collapsible Grade 10–11 class grid. |
| [`README_T.md`](README_T.md) | Markdown | Summarizes immediate teacher files and folders, their documented interfaces, and available section information for repository navigation. |

## Folders

| Folder | Purpose | README |
|---|---|---|
| [`assets/`](assets/) | Supplies timetable, calendar, class-view, and theme styles and scripts, schedule data, and a retained schedule prototype. | None. |
| [`authoring/`](authoring/) | Maintains dated meetings in `schedule.csv`, stable lessons and materials in `lessons.json`, and Node tools for validation, dataset generation, cancellation, and lesson rescheduling; consult its workflow before changing schedule assignments. | [`README.md`](authoring/README.md) |
| [`pages/`](pages/) | Provides class-detail and combined schedules, the live projector view, school-day timer, academic calendar, Magis and Seminarios resources, a summation lesson, and compatibility class redirects. | None. |
| [`pause/`](pause/) | Purpose unavailable: the previous summary provides no description and no qualifying immediate child README is available. | None. |
| [`tools/`](tools/) | Provides the student-picture visualizer and name-matching practice, an experimental browser schedule authoring tool, and a dated assessment-workbook normalizer. | None. |

# Directory Summary

## Purpose

Shared LaTeX preambles, graph macros, visual assets, and inventory guidance support the project's 2026–2027 teaching materials.

## Files

| File | Type | Purpose |
|---|---|---|
| [`global_economics_cover.tex`](global_economics_cover.tex) | LaTeX | Renders a full-page, image-based letter-size cover with varied histogram heights; text and graph are embedded in the artwork. |
| [`preamble-unused.tex`](preamble-unused.tex) | LaTeX | Unavailable: older source has no prior description. |
| [`preamble.tex`](preamble.tex) | LaTeX | Defines shared packages, page settings, colors, frames, images, hyperlinks, navigation, and criterion-based tasks. |

| [`preamble_exams-unused.tex`](preamble_exams-unused.tex) | LaTeX | Unavailable: older source has no prior description. |

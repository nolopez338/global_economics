# Directory Summary

## Purpose

Provides Grade 11 Term 2 practice activities on statistical estimation and confidence intervals, with worked economic and financial examples covering criteria C1 through C10.

## Files

| File | Type | Purpose |
|---|---|---|
| [`G11_T2_L1_C1_practice.tex`](G11_T2_L1_C1_practice.tex) | LaTeX | Teaches C1 distinctions between population parameters and sample statistics by comparing means, standard deviations, and proportions across new samples and expanded populations. |
| [`G11_T2_L1_C2_practice.tex`](G11_T2_L1_C2_practice.tex) | LaTeX | Teaches C2 point and interval estimation and long-run confidence coverage through a stall-fee simulation and household energy-bill reports. |
| [`G11_T2_L1_C3_practice.tex`](G11_T2_L1_C3_practice.tex) | LaTeX | Teaches C3 how the point estimate, critical value, standard error, and margin of error determine the centre and width of a confidence interval. |
| [`G11_T2_L1_C4_practice.tex`](G11_T2_L1_C4_practice.tex) | LaTeX | Teaches C4 construction and interpretation of one-sample z intervals for a mean with known population variance using courier earnings and warehouse charges. |
| [`G11_T2_L2_C5_practice.tex`](G11_T2_L2_C5_practice.tex) | LaTeX | Teaches C5 how to check assumptions, construct one-proportion z intervals, and interpret default and shipment-delay rates against benchmarks. |
| [`G11_T2_L2_C6_practice.tex`](G11_T2_L2_C6_practice.tex) | LaTeX | Teaches C6 minimum sample-size planning for means and proportions using a target margin of error, upward rounding, and pilot or conservative inputs. |
| [`G11_T2_L2_C7_practice.tex`](G11_T2_L2_C7_practice.tex) | LaTeX | Teaches C7 how sample size and confidence level affect interval width, using mobile-ticketing surveys to compare precision and coverage. |
| [`G11_T2_L3_C8_practice.tex`](G11_T2_L3_C8_practice.tex) | LaTeX | Teaches C8 construction and interpretation of Student's t intervals for a population mean with unknown variance through loading-time and customs-processing examples. |
| [`G11_T2_L3_C9_practice.tex`](G11_T2_L3_C9_practice.tex) | LaTeX | Teaches C9 how to evaluate confidence-interval inferences by checking selection bias, independence, outcome counts, distributional shape, and outliers. |
| [`G11_T2_L3_C10_practice.tex`](G11_T2_L3_C10_practice.tex) | LaTeX | Teaches C10 how to design, analyse, and report a merchant fee revenue study using a confidence interval, a precision target, and a budgeting benchmark. |
| [`README-G11T2PA.md`](README-G11T2PA.md) | Markdown | Summarizes this directory, its source files, public commands, and document sections. |

# Directory Summary

## Purpose

Provides Grade 11 Term 2 Lesson 1 LaTeX classroom activities on population and sample measures, point and interval estimation, and confidence-interval precision and reliability.

## Files

| File | Type | Purpose |
|---|---|---|
| [`G11_T2_L1_C1_classroom_activity.tex`](G11_T2_L1_C1_classroom_activity.tex) | LaTeX | Teaches population parameters versus sample statistics through notation tables, one worked sales survey, one guided checkout survey, three independent comparisons, and solutions enabled by default; consult for C1 identification and changes in population scope. |
| [`G11_T2_L1_C2_classroom_activity.tex`](G11_T2_L1_C2_classroom_activity.tex) | LaTeX | Teaches known-standard-deviation point and interval estimation, observed coverage, and percentage-point discrepancies through one worked cycling example, one guided printing-cost example, four independent problems, and appended highlighted solutions; consult for C2 coverage interpretation. |
| [`G11_T2_L1_C3_classroom_activity.tex`](G11_T2_L1_C3_classroom_activity.tex) | LaTeX | Teaches confidence-interval components through one worked grocery-spending example, one guided delivery-charge example, and three independent problems, each comparing sample size and confidence with six graphs, normal panels, endpoints, and widths; consult for C3 precision and reliability. |
| [`README-B_G11_T2_CA.md`](README-B_G11_T2_CA.md) | Markdown | Summarizes the immediate classroom-activity sources, their locally defined commands, and explicit document sections for repository navigation. |

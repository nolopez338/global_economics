# Directory Summary

## Purpose

This folder provides Grade 11 Term 1 probability and statistics practice activities with worked solutions for criteria C1–C9.

## Files

| File | Type | Purpose |
|---|---|---|
| [`G11_T1_C1_practice_activity.tex`](G11_T1_C1_practice_activity.tex) | LaTeX | Provides solved exercises identifying discrete and continuous probability distributions in economic contexts. |
| [`G11_T1_C2_practice_activity.tex`](G11_T1_C2_practice_activity.tex) | LaTeX | Provides solved geometric probability exercises for uniform, linear, triangular, piecewise uniform, and piecewise linear densities. |
| [`G11_T1_C3_practice_activity.tex`](G11_T1_C3_practice_activity.tex) | LaTeX | Provides solved circular uniform and triangular probability exercises involving directions, cycle cuts, and wrapped intervals. |
| [`G11_T1_C4_practice_activity.tex`](G11_T1_C4_practice_activity.tex) | LaTeX | Provides solved exponential-distribution exercises on random variables, probabilities, and rate parameters. |
| [`G11_T1_C5_practice_activity.tex`](G11_T1_C5_practice_activity.tex) | LaTeX | Provides solved exercises on continuous-distribution means, variances, standard deviations, and probabilities within one standard deviation. |
| [`G11_T1_C6C7_practice_activity.tex`](G11_T1_C6C7_practice_activity.tex) | LaTeX | Provides solved exercises comparing empirical and theoretical probabilities and sample statistics using raw, frequency, grouped, and histogram data. |
| [`G11_T1_C8_practice_activity.tex`](G11_T1_C8_practice_activity.tex) | LaTeX | Provides explanations and solved Student's t-table exercises on critical values, symmetry, and probability bounds. |
| [`G11_T1_C9_practice_activity.tex`](G11_T1_C9_practice_activity.tex) | LaTeX | Provides solved exercises choosing and comparing standard normal and Student's t models, probability areas, and critical values. |
| [`README-G11T1PA.md`](README-G11T1PA.md) | Markdown | Summarizes this directory, its sources, commands, and document sections. |

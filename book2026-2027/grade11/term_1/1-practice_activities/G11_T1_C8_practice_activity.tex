Page 2 gives positive Student's $t$ critical values for upper-tail probabilities
$0.30,0.20,0.10,0.05,0.025,0.01,0.005$, for df $1$--$30$ and selected larger df.
Use only this Student's $t$ table; no CDF or inverse-CDF calculator is needed.

\textbf{Models and simplifying approximation.} Each question supplies a continuous model
for an individual signed deviation $X$: negative means below the reference and positive means above it.
The supplied model is $X=m+aT$, where $T\sim t_\nu$, $a>0$, and $\boxed{\nu=n-1}$.
Here $n$ is the stated sample size and $m$ is the supplied mean deviation.
Use the supplied ``approximate standard deviation'' directly as the scale $a$, as in the classroom activity.
This is a teaching approximation: the actual model SD is
\[
\operatorname{SD}(X)=a\sqrt{\frac{\nu}{\nu-2}}\quad(\nu>2).
\]
All problems here have $\nu>2$. The actual SD exceeds $a$; the approximation improves as $\nu$ increases.
Use the supplied $a$ without adjusting it. The individual-deviation $t$ model and the choice
$\nu=n-1$ are stipulated assumptions; sample size alone does not imply this distribution.

No raw-data SD calculation is required. If calculating from data, distinguish sample
$s=\sqrt{\sum_{i=1}^{n}(x_i-\bar x)^2/(n-1)}$ from population
$\sigma=\sqrt{\sum_{i=1}^{N}(x_i-\mu)^2/N}$; both have the original measurement units.
These questions concern individual deviations, so standardize with $a$, not $a/\sqrt n$.
A denominator $s/\sqrt n$ is an estimated standard error of the sample mean, used for inference about a population mean in a different setting.

\textbf{Using the supplied table.} In row $\nu$ and column $\alpha$, the positive critical value
$t^*$ satisfies $P(T>t^*)=\alpha$ to the table's precision. By symmetry,
\[
P(T<-t^*)=\alpha,\qquad P(T<t^*)=1-\alpha,\qquad P(T>-t^*)=1-\alpha.
\]
An interval probability is the difference of cumulative areas, or 1 minus the two excluded tails.
Add disjoint outside tails. Endpoints have probability zero.

\textbf{Procedure for independent work.}
\begin{enumerate}
\item Define $X$ and its units. Record $n$, $m$, $a$, and $\nu=n-1$; write the requested event.
\item For direct problems, standardize each boundary with $t=(x-m)/a$.
Identify the row and upper-tail column for its absolute value, then use symmetry,
complements, or addition/subtraction to find the requested probability.
\item For inverse problems, identify the required tail probabilities first.
A central area $p$ leaves $(1-p)/2$ in each tail; combined symmetric tails $q$ leave $q/2$ in each tail.
Read $t^*$ from row $\nu$, choose the correct sign, and back-transform with $x=m+at$.
Equal-tail limits are $L=m-at^*$ and $U=m+at^*$.
\item Show calculations and table rows/columns, then interpret the result in the original units.
Attempt each task before checking its worked solution.
\end{enumerate}

\textbf{Precision.} Table entries are rounded to three decimals. Direct boundaries retain enough
digits to recover them: do not first round these contextual boundaries to two decimals.
Report probabilities as implied by the table; these approximate the continuous model's areas
because the tabulated boundaries are rounded. For inverse problems use the three-decimal table
entry in the back-transformation, then round the final contextual cutoff to two decimals
(round halfway values away from zero). Do not substitute higher-precision calculator quantiles.
Diagrams shade the requested region; curves continue beyond the displayed range.

\subsection{Delivery schedule deviations}
\label{c8-d1}
\textbf{Problem.} A courier uses a heavy-tailed planning model for delivery schedule deviations. Negative deviations mean early arrivals. Let $X$ be delivery time minus its scheduled time, measured in minutes. A sample of 10 deliveries has mean deviation $m=0$ and approximate standard deviation $5$ minutes. Use the supplied model $X=0+5T$, where $T\sim t_{9}$ and $\nu=n-1=9$. Use the approximate SD directly as scale $a=5$ minutes.
\QuestionsTasks[sec:c8-direct]{{8}/{sol:c8-d1}/{Find the probability that a delivery arrives less than 6.915 minutes late (including early arrivals), and the probability that it arrives more than 4.415 minutes early. Write each event, standardize the boundaries, identify the table row and tail columns, calculate the probabilities, and interpret each result.}}
\subsubsection*{Worked solution}\phantomsection\label{sol:c8-d1}
\par\textbf{Translating the information into mathematics}
Here $n=10$, so $\nu=10-1=9$. Use $m=0$ and the supplied approximate SD as scale $a=5$:
\[X=0+5T,\qquad T=\frac{X-0}{5},\qquad T\sim t_{9}.\]
\par\textbf{Part 1.} Standardize using the supplied scale:
\[t_{1}=\frac{6.915-0}{5}=1.383\]
\[P(X<6.915)=P(T<1.383).\]
Row $9$, column $\alpha=0.10$: $t^*=1.383$, so $P(T>1.383)=0.10$.
Use symmetry and a complement as needed.
\[P(X<6.915)=1-0.10=\boxed{0.9}.\]

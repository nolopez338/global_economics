# Directory Summary

## Purpose

Provides Grade 10 Term 1 practice activities on payoff tables, decision criteria under uncertainty and risk, probability sensitivity, and decision trees.

## Files

| File | Type | Purpose |
|---|---|---|
| [`compile_all_tex.bat`](compile_all_tex.bat) | Batch | Compiles all `.tex` files recursively with `latexmk` and reports success or failure. |
| [`G10_T1_L1_C1C2_practice_activity.tex`](G10_T1_L1_C1C2_practice_activity.tex) | LaTeX | Develops C1–C2 decision elements and payoff-table construction through direct, variable, fixed, and combined payoff models. |
| [`G10_T1_L1_C1C2_practice_activity1-alternate-descriptions.tex`](G10_T1_L1_C1C2_practice_activity1-alternate-descriptions.tex) | LaTeX | Presents narrative C1–C2 scenarios explaining direct payoffs and variable/fixed components, without the main activity's general introduction. |
| [`G10_T1_L1_C1C3_practice_activity.tex`](G10_T1_L1_C1C3_practice_activity.tex) | LaTeX | Develops C1/C3 profit tables by calculating revenue minus costs across direct and one- to four-component models. |
| [`G10_T1_L1_C1C3_practice_activity2-alternate-descriptions.tex`](G10_T1_L1_C1C3_practice_activity2-alternate-descriptions.tex) | LaTeX | Recasts C1/C3 revenue-and-cost problems as narrative scenarios with numerical data for calculating profit payoffs. |
| [`G10_T1_L1_C1C3_practice_activity2newproposal.tex`](G10_T1_L1_C1C3_practice_activity2newproposal.tex) | LaTeX | Proposes a C1/C3 variant using cell-specific per-unit revenue and cost rates alongside alternative- and state-based fixed amounts. |
| [`G10_T1_L1_C4_practice_activity.tex`](G10_T1_L1_C4_practice_activity.tex) | LaTeX | Explains and solves Maximax and Maximin choices using general, coffee-shop, clothing-store, and technology-company payoff tables. |
| [`G10_T1_L2_C4C5_practice_activity3.tex`](G10_T1_L2_C4C5_practice_activity3.tex) | LaTeX | Applies Maximax, Maximin, and Minimax Regret to symbolic examples and contextual problems with varied payoff-table dimensions. |
| [`G10_T1_L2_C5_practice_activity.tex`](G10_T1_L2_C5_practice_activity.tex) | LaTeX | Explains opportunity-loss tables and solves Minimax Regret problems in general and business contexts. |
| [`G10_T1_L2_C6_practice_activity.tex`](G10_T1_L2_C6_practice_activity.tex) | LaTeX | Calculates expected monetary values and Bayes choices in solved general and business problems with stated probabilities. |
| [`G10_T1_L2_C6C7_practice_activity_old.tex`](G10_T1_L2_C6C7_practice_activity_old.tex) | LaTeX | Provides an older combined activity on EMV/Bayes choices and probability thresholds for marketing, production, and zoning alternatives. |
| [`G10_T1_L2_C7_practice_activity.tex`](G10_T1_L2_C7_practice_activity.tex) | LaTeX | Solves probability-sensitivity problems using expected-value functions, indifference thresholds, preference regions, and graphs. |
| [`G10_T1_L3_C8_practice_activity.tex`](G10_T1_L3_C8_practice_activity.tex) | LaTeX | Compares Maximax, Maximin, Minimax Regret, and EMV/Bayes through worked examples, contextual practice, and critiques of decision claims. |
| [`G10_T1_L3_C9_practice_activity.tex`](G10_T1_L3_C9_practice_activity.tex) | LaTeX | Teaches decision-tree construction, error repair, and backward induction through worked, guided, and independent multistage problems. |
| [`G10_T1_practice_activities_summary.tex`](G10_T1_practice_activities_summary.tex) | LaTeX | Summarizes C1–C7 activity topics and tasks for payoff tables, profit calculations, decision criteria, and probability sensitivity. |
| [`README-G10T1PA.md`](README-G10T1PA.md) | Markdown | Summarizes this directory's practice sources and compilation script. |

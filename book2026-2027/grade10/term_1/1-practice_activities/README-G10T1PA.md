# Directory Summary

## Purpose

Provides Grade 10, Term 1 LaTeX practice materials that develop decision modelling, quantitative payoff analysis, criterion-based recommendations, and staged filtering for classroom practice and revision.

| [`README-G10T1PA.md`](README-G10T1PA.md) | Markdown | Summarizes the source inventory, criterion coverage, learning progression, and document organization. |

The main learning progression is **C1–C3: model the decision and construct profit payoffs → C4–C5: compare outcomes without probabilities → C6: weight payoffs by probabilities → C7: test probability sensitivity → C8: compare and justify criteria → C9: apply criteria sequentially to surviving alternatives**. The narrative variants support interpretation of prose; the proposal variant extends the component framework; the combined C4–C5 file consolidates the separate criterion activities. No current source in this folder explicitly evaluates **C10**.

C8 and C9 use related statistics for different purposes: C8 compares recommendations and, where instructed, updates payoffs and recalculates regrets over eligible alternatives; C9 keeps all original statistics fixed, retains cutoff ties, and permanently excludes eliminated alternatives. C9 trees show survivors to the right and eliminations downward.

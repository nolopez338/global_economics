\subsection{Coastal Recycling Collection (C1--C2)}
\label{sec:problem20-coastal-recycling-collection-c1-c2}
A decision maker must choose one of \textbf{3 alternatives} before learning which of \textbf{3 states} occurs. All monetary amounts are in USD unless stated otherwise.
\begin{multicols}{2}
\begin{enumerate}[label=\arabic*.]
 \item \textbf{Alternatives}
 \begin{enumerate}[label=\roman*)]
  \item Small collection plan
  \item Medium collection plan
  \item Large collection plan
 \end{enumerate}
 \item \textbf{States of nature}
 \begin{enumerate}[label=\roman*)]
  \item Calm season
  \item Windy season
  \item Storm-alert season
 \end{enumerate}
\end{enumerate}
\end{multicols}
 \textbf{Numerical information}
 \begin{enumerate}[label=\roman*)]
  \item Tonnes collected: Small 300, 260, 210; Medium 450, 390, 320; Large 600, 510, 400. Income per tonne: all plans USD 40.
  \item State-based variable cost per tonne: Calm USD 18; Windy USD 22; Storm alert USD 27. State-based fixed port cost: Calm USD 1,500; Windy USD 2,300; Storm alert USD 3,500.
 \end{enumerate}
Subtract both a state-based per-unit cost and a state-based fixed cost; each is shared by all alternatives within that state. Calculate every payoff using
\[
 \text{Payoff}=\text{collection income}-\text{applicable cost or costs}.
\]

\section{Introduction}\label{sec:c9-introduction}
The summary tables provide four statistics for each alternative, all in thousand USD and rounded to two decimal places. Use these supplied statistics directly; you are not required to recalculate them from the payoff matrices.
\begin{itemize}
\item \textbf{Maximax:} select the highest Max Payoff (the alternative's maximum payoff).
\item \textbf{Maximin:} select the highest Min Payoff (the alternative's minimum payoff).
\item \textbf{Minimax Regret:} select the lowest Max Regret. Regret in each state is the best payoff among all six original alternatives in that state minus the alternative's payoff; Max Regret is the largest of these regrets.
\item \textbf{EMV (Expected Monetary Value):} select the highest EMV, calculated using the stated probabilities as payoff weights.
\end{itemize}
Apply each problem's filtering rules sequentially. Compare only alternatives retained from the preceding stage; eliminated alternatives cannot reenter. All original summary statistics remain fixed: do not recalculate any statistic after eliminating alternatives. When asked to keep the best $k$ alternatives, retain every alternative tied at the cutoff, even if more than $k$ remain. At the final stage, report a tie explicitly if multiple alternatives share the best value.

Represent each process in a four-column filtering table: \# Step, Description, Left Alternatives, and Eliminated Alternatives. Step 0 lists all six alternatives. For each subsequent stage, record the criterion, filtering rule, relevant numerical values, and alternatives retained or eliminated at that stage. Identify the final selected alternative (or tied alternatives) in the last row. The problems use two to four filtering stages and vary the criteria applied.

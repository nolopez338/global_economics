\section{Introduction}\label{sec:c9-introduction}
Use the already calculated EV, Maximin, and Maximum Regret summary tables directly; do not recompute these statistics from the payoffs. Apply the filtering rules in the specified order. At each stage, compare only the alternatives retained by the previous stage. Higher EV and Maximin values are preferred; smaller maximum regrets are preferred. Keep the supplied regret values fixed while filtering.

Represent each sequential decision process in a four-column filtering table: \# Step, Description, Left Alternatives, and Eliminated Alternatives. Start with all alternatives at step 0; then record the criterion, filtering rule, relevant values, and alternatives retained or eliminated at steps 1--3. Identify the final selected alternative in the last row. Retain tied alternatives together; do not introduce an arbitrary tie-breaking rule. State probabilities belong to the payoff model used to calculate EV.

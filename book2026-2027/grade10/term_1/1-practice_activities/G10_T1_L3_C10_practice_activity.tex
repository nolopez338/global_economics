	\maketitle
	
	Create and deploy an \textbf{individual interactive decision webpage} that allows users to enter, modify, and analyze decision-making problems under uncertainty. Use the \textbf{C10 reference dashboard} as the functional model and apply your learning from C1--C9.
	
	\section*{Requirements}
	\begin{enumerate}[label=\textbf{\arabic*.},leftmargin=*]
		
		\item \textbf{Interactive decision model.}
		Develop a webpage that allows users to:
		\begin{itemize}
			\item Add, edit, and remove alternatives and states of nature.
			\item Enter and modify payoff values in an interactive table.
			\item Enter and adjust state probabilities for probabilistic criteria.
			\item Calculate and compare \textbf{Maximax, Maximin, Minimax Regret, and EMV/Bayes}, including the corresponding values and recommended alternatives.
			\item Apply \textbf{staged filtering} and visualize each elimination step.
			\item Display a \textbf{flow diagram} representing the staged-filtering process and its final outcome.
		\end{itemize}
		
		All calculations and visualizations must update automatically when the input data change. Correctly identify ties when applicable.
		
		\item \textbf{Preloaded examples.}
		Include at least \textbf{two distinct, preloaded decision problems} that users can select directly from the webpage. Each example must contain alternatives, states of nature, payoff values, and probabilities. The examples must demonstrate and allow users to verify the correct functioning of all decision criteria, staged filtering, and the flow diagram.
		
		\item \textbf{Functionality and usability.}
		Ensure the webpage is accurate, responsive, and easy to use. Clearly organize the input tables, calculation results, filtering stages, and flow diagram. Handle invalid inputs appropriately and ensure consistency between all displayed results.
		
		\item \textbf{AI development record.}
		Include a visible, accessible \textbf{hyperlink to the AI conversation used to develop the webpage}.
		
		\item \textbf{Submission.}
		Submit only the \textbf{deployed webpage URL}, publicly accessible through a web browser. No written decision context, separate analysis, or additional document is required.
		
		\textbf{Reference example:}
		
		\begin{center}
			\url{https://nolopez338.github.io/global_economics/grade10/src/pages/term1/g10-t1-c10dashboard.html}
		\end{center}
		
		\textit{Note: The reference dashboard demonstrates the expected functionality and includes all required features except the hyperlink to the AI development conversation. Your webpage must include this additional element.}
		
	\end{enumerate}
	
	\medskip
	\noindent\textbf{C10 approval condition:}
	To pass Criterion 10, \textbf{all five requirements above must be fully satisfied}. Partial completion of any requirement is insufficient for C10 approval.

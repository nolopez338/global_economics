\section{Overview}

\code{term\_1} is a LaTeX source collection for a Grade 10 Global Economics unit on decision analysis. It progresses from C1–C2 practice (identifying decision components and constructing payoff tables), through C1–C10 assessments and worked solutions, to criterion-specific recovery activities and supplementary material.

Files described as \textbf{student-facing} are worksheets, assessments, or briefs intended to receive student work; files described as \textbf{teacher material} expose worked answers or instructional solution sets. There are no local HTML pages, stylesheets, JavaScript programs, datasets, configuration files, or standalone media. The JavaScript item is a student project \emph{brief}, not an implementation.

\section{Directory structure}

The inventory has four top-level directories. Each file below is a standalone LaTeX document; the displayed name is its exact stored filename.

\subsection{\code{1-practice\_activities/}}

This directory contains student practice and an instructor-facing contents summary for Lesson 1 decision components and payoff tables.

\begin{itemize}
  \item \code{G10\_T1\_L1\_C1-C2\_practice\_activity1.tex}

  Student-facing C1–C2 workbook: 21 scenarios spanning direct, variable, fixed, and hybrid payoff models, with guided interpretations and computed tables.

  \item \code{G10\_T1\_L1\_C1-C2\_practice\_activity2 - Copy.tex}

  Compact alternate/legacy Activity 2: 14 terse scenario notes and partial calculations based largely on Activity 1 contexts. Unlike the full Activity 2, it is not a nine-problem worked worksheet.

  \item \code{G10\_T1\_L1\_C1-C2\_practice\_activity2.tex}

  Student-facing worked C1–C2 activity with nine new contexts (food truck through emergency supplies), each identifying decision elements and building a payoff table.

  \item \code{G10\_T1\_summary.tex}

  Teacher/contributor summary that inventories the modeling categories and scenario counts in the two Lesson 1 practice activities.
\end{itemize}

\section{Important relationships}

\subsection{Student and teacher document relationships}

\begin{itemize}
  \item All entries are standalone LaTeX documents. Solution files are teacher companions to the like-named student assessment or activity unless a different relationship is explicitly noted in the directory inventory. None is loaded by another file in this directory.
  \item The alternate C1–C5 exam solution changes state sets and probabilities and expands alternatives relative to the main Lesson 1 exam key.
  \item The hard supplementary solution belongs to a harder parallel five-problem set and is not the direct key to the standard student supplementary sheet. The standard supplementary solution is the matching key.
  \item The reference midterm is a teacher reference solution set rather than a blank student midterm.
\end{itemize}

\subsection{Shared preambles and external dependencies}

\begin{itemize}
  \item Most solution, supplementary, and material documents load the shared \code{preamble/preamble\_exams.tex}, located outside \code{term\_1}. Catch-up keys reach it with \code{../../../preamble/preamble\_exams.tex}; most other keys and materials use \code{../../preamble/preamble\_exams.tex}.
  \item The practice activities and summary load the external shared \code{preamble.tex} through a multi-directory \code{\textbackslash{}input@path}.
  \item Student assessment sheets that define their own page layout embed the shared \code{preamble/logo.png} via relative paths. There are no images or other media physically inside \code{term\_1}.
\end{itemize}

\subsection{Graph macros and external assets}

Activity 2, its compact copy, and the summary additionally load three shared graph-macro files:
\begin{itemize}
  \item \path{graphs/uniform_linear_probability_distributions.tex}
  \item \path{graphs/probability_distribution_graphs.tex}
  \item \path{graphs/normal_distribution_graphs.tex}
\end{itemize}
These files define reusable graph commands; no graph image files are stored here.

\subsection{Project files and supporting resources}

\begin{itemize}
  \item \code{G10\_T1\_L3\_proyect.tex} specifies interactive web-page elements and JavaScript functions as student deliverables. The directory contains no HTML, CSS, or JavaScript implementation to which the brief links.
  \item \code{G10\_T1\_L3\_proyect\_problems.tex} supplies the ten datasets and tasks used by the full and minimal project solution documents.
  \item \code{G10\_T1\_L3\_MATERIAL.tex} is separate worked enrichment rather than a generated build artifact.
\end{itemize}

\subsection{Generated, absent, and intentionally omitted files}

No generated LaTeX outputs (\code{.aux}, \code{.log}, \code{.out}, \code{.toc}, or PDFs), dependency directories, editor caches, or meaningful hidden files are present. \code{STRUCTURE.md} is intentionally omitted from the directory inventory because it is this inventory document.

\section{Classification summary}

\begin{itemize}
  \item \textbf{Student-facing resources:} blank activities, exams, midterms, catch-ups, supplementary worksheets, and project briefs or problem banks identified above.
  \item \textbf{Teacher and solution resources:} all worked \code{solution} and anomalously named \code{soution} files, reference and material sets, and the practice summary.
  \item \textbf{Shared dependencies:} LaTeX preambles, graph definitions, and the logo, all located outside this directory.
  \item \textbf{Resource types not locally present:} stylesheets, JavaScript implementations, data, configuration files, and local media. No HTML pages are present either.
  \item \textbf{Generated or build-related files:} none present.
\end{itemize}

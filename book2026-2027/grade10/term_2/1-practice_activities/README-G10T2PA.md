# Directory Summary

## Purpose

Provides Grade 10 Term 2 discrete-probability practice activities with worked economic and financial examples, supporting validation notes, and a numerical audit script.

## Files

| File | Type | Purpose |
|---|---|---|
| [`G10_T2_L1_C1_practice_activity.tex`](G10_T2_L1_C1_practice_activity.tex) | LaTeX | Teaches C1 outcome mappings, discrete support, and probability mass functions through finite and infinite models, graphs, and solved financial problems. |
| [`G10_T2_L1_C2_practice_activity.tex`](G10_T2_L1_C2_practice_activity.tex) | LaTeX | Teaches C2 PMF and CDF properties, cumulative probabilities, jumps, endpoints, and invalid-model checks through solved financial problems. |
| [`G10_T2_L1_C3_practice_activity.tex`](G10_T2_L1_C3_practice_activity.tex) | LaTeX | Teaches C3 Bernoulli indicators, success-label reversal, and monetary consequences through solved default, claim, payment, and sales problems. |
| [`G10_T2_L1_C4_practice_activity.tex`](G10_T2_L1_C4_practice_activity.tex) | LaTeX | Teaches C4 binomial assumptions and exact, interval, and complementary probabilities for fixed financial trials. |
| [`G10_T2_L2_C5_practice_activity.tex`](G10_T2_L2_C5_practice_activity.tex) | LaTeX | Teaches C5 geometric waiting times, cumulative and tail probabilities, memorylessness, and trial-versus-failure conventions. |
| [`G10_T2_L2_C6_practice_activity.tex`](G10_T2_L2_C6_practice_activity.tex) | LaTeX | Teaches C6 negative binomial total trials to a fixed success target, deadline probabilities, and failure-count conversions. |
| [`G10_T2_L2_C7_practice_activity.tex`](G10_T2_L2_C7_practice_activity.tex) | LaTeX | Teaches C7 Poisson counts, rate-times-exposure scaling, probability complements, and limitations caused by clustered events. |
| [`G10_T2_L3_C8_practice_activity.tex`](G10_T2_L3_C8_practice_activity.tex) | LaTeX | Teaches C8 expected value, variance, standard deviation, monetary transformations, and limits of dispersion as a financial-risk measure. |
| [`G10_T2_L3_C9_practice_activity.tex`](G10_T2_L3_C9_practice_activity.tex) | LaTeX | Teaches C9 selection and justification of Bernoulli, binomial, geometric, negative binomial, and Poisson models using observation rules and assumptions. |
| [`README-G10T2PA.md`](README-G10T2PA.md) | Markdown | Summarizes this directory, its source files, public entry point, and document sections. |

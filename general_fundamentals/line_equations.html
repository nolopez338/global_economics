Start with a story

Where do straight-line patterns appear?

Whenever one quantity changes by the same amount for every equal change in another, a linear model may fit.

🚕

Taxi fare

A base fare plus the same price for each kilometre: C(x)=mx+b.

x = distance · m = price/km · b = base fare
💼

Hourly earnings

An initial amount plus a fixed amount earned each hour.

💧

Water tank

Water increases—or decreases—with a constant flow rate.

🌡️

Temperature

Celsius and Fahrenheit are connected by a linear conversion.

🚲

Steady motion

At constant speed, distance changes evenly with time.

Reality check: not every relationship is linear. A car that speeds up, a curved ball flight, or compound interest has a changing rate. Linear models require a constant rate (or clearly state that they are an approximation).

Cause and effect

What does the slope m control?

Keep b fixed and compare. Direction comes from the sign; steepness comes from the size of |m|.

Rapid slope comparisons

Predict first: will the line rise, fall, or stay level?

m > 0: increasing · m < 0: decreasing · m = 0: constant. Large |m| is steeper; small nonzero |m| is flatter.

Move the intercept, not the tilt

Keep m fixed; change b. The whole line moves vertically, but its slope does not change.

f(x)=2x−3
g(x)=2x
h(x)=2x+3

Same slope + different intercepts = parallel lines. Same slope + same intercept = the identical line.

Slope from points

Any two points tell the same rate

Select two distinct x-values. The run and rise change, but their ratio stays m.

Choose points on the current line

A nonvertical function has one output for each input, so distinct x-values make Δx nonzero.

Why the ratio stays constant

For y = mx+b, subtracting outputs cancels b:

y₂−y₁ = (mx₂+b)−(mx₁+b)
= m(x₂−x₁)
so (y₂−y₁)/(x₂−x₁) = m

The slope triangle on the main graph draws the same horizontal run and vertical rise.

Boundary cases

Important lines to recognize

Send any case to the laboratory and inspect its equation, table, and graph.

f(x) = x

m = 1, b = 0. Rise 1 for every run 1.

f(x) = −x

m = −1, b = 0. Fall 1 for every run 1.

f(x) = b

m = 0. A horizontal, constant function.

f(x) = mx

b = 0. Every such line passes through the origin.

What about x = 3? It is a vertical line, but it cannot be written as f(x)=mx+b. At the single input x=3 there are many possible y-values, breaking the rule that a function maps each input to exactly one output. Its slope would also require division by a run of zero.

Language connected to action

Words for what you observed

Linear function
A one-output-per-input rule with a constant rate; its graph is a nonvertical straight line.
Input / independent variable
The x-value chosen before the function acts.
Output / dependent variable
f(x) or y; its value depends on x.
Function notation
f(3) means the output at x=3—not f multiplied by 3.
Slope / rate of change
m=rise/run=Δy/Δx, the output change per input unit.
y-intercept
b=f(0), where the graph meets the vertical axis.
Ordered pair
(x,f(x)), an input and its output plotted as one point.
Coordinate plane
The x- and y-axes, grid, and locations used to graph pairs.
Increasing / decreasing / constant
As x grows, output rises (m>0), falls (m<0), or stays fixed (m=0).

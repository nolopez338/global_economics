Discrete Probability Distributions

Model uncertain outcomes, compare return and risk, and justify an investment choice.

Grade 10 · Global Economics · Term 2

From uncertain returns to an investment choice

  1. Step 1

    Describe uncertain returns

    • Support
    • Exact probability
    • Cumulative probability

    Let X be Investment A’s annual return, recorded as 2, 4 or 6 when expressed as a percentage. These possible values form its support. The probability mass function (PMF) gives the probability of each exact outcome. The cumulative distribution function (CDF) gives the probability that X is at or below a threshold.

    Criteria for this step

    Characterises discrete random variables in economic and financial contexts by identifying their support, probability mass function and possible outcomes.

    Criteria for this step

    Interprets PMFs and CDFs by verifying their defining properties and using them to calculate point, interval, cumulative, and complementary probabilities in financial contexts.

  2. Step 2

    Count outcomes in fixed trials

    • Trial outcome
    • Model conditions
    • Exact probability

    For one loan, a Bernoulli indicator is 1 if it defaults within a year and 0 if it does not. “Success” means the event we count, so here it means a default. Let X count defaults across four loans over that year.

    Criteria for this step

    Models binary economic outcomes with Bernoulli random variables, interpreting success and failure in contexts such as default, gain, loss, or claim occurrence.

    Criteria for this step

    Applies the binomial distribution to fixed-trial financial situations by verifying its conditions and calculating probabilities using the binomial probability formula P(X = k) = C(n, k) × p^k × (1 − p)^(n − k).

  3. Step 3

    Count trials until success or events in an interval

    • What ends the count

    To model sales calls, assume independent trials with the same probability p = 0.20 of a sale on each call. Count all calls up to and including the final sale. For rare insurance claims, count events in one week. A Poisson model is reasonable if the rate is stable and events occur independently. Its parameter λ is the expected count in that week.

    Criteria for this step

    Models waiting-time situations with geometric distributions, calculating the probability of the first success occurring on a given trial in financial or business contexts.

    Criteria for this step

    Applies the negative binomial distribution to situations that count the number of trials needed to obtain a fixed number of successes.

    Criteria for this step

    Evaluates rare-event situations with the Poisson distribution, interpreting the parameter λ in contexts such as claims, arrivals, defects, or defaults within a fixed interval.

  4. Step 4

    Measure return and risk, then choose a model

    • Expected return
    • Variance
    • What is counted
    • Model conditions

    Expected return is the long-run average over repeated years under the same distribution. Variance measures spread around that average in squared units. To choose a probability model for a new situation, ask what the variable counts and check the assumptions.

    Criteria for this step

    Calculates and interprets the expected value and variance of discrete probability distributions as measures of return and risk in economic and financial contexts.

    Criteria for this step

    Compares Bernoulli, binomial, negative binomial, geometric, and Poisson distributions by selecting the most appropriate model for a given financial-risk situation.

  5. Step 5

    Justify an investment choice

    Screen two hypothetical investments for inclusion in a portfolio over the same one-year horizon. Compare each investment’s expected return with its spread and the possibility of a loss.

    • Expected return
    • Variance

    Criteria for this step

    Assesses investment alternatives for inclusion in a portfolio by comparing their discrete return distributions, expected returns, variances, and risk–return trade-offs, using the results to support investment portfolio decision-making.

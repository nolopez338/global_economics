  1. Introduction · Decision under uncertainty

    Local Café Investment

    A café must decide whether to launch a new line of artisan desserts or keep its current menu before it knows the actual foot traffic. The possible states are high traffic and low traffic. Each decision–traffic combination has different economic consequences: projected profits of 42 or 8 thousand USD for the dessert line, and 28 or 20 thousand USD for the current menu.

  2. Introduction · Decision elements

    Identify the four elements

    Café decision elements
    AlternativesLaunch dessert line; keep current menu
    States of NatureHigh traffic; low traffic
    EventActual foot traffic after the decision
    ConsequencesThe profit outcome produced by each alternative–state pair

    The decision-maker controls the alternative, but not which state the uncertain event produces.

  3. Introduction · Payoff table

    Organize every alternative–state pair

    Alternatives form the rows; states of nature form the columns. Each cell holds one numerical payoff.

    Café profit (thousand USD)
    AlternativeHigh trafficLow traffic
    Launch dessert line428
    Keep current menu2820

  4. Payoff construction · 1

    From consequence to payoff

    Alternative Ai+State Sj→Consequence→Payoff Pij
    • The decision-maker selects Ai.
    • The uncertain event determines which Sj occurs.
    • The pair (Ai,Sj) produces a consequence.
    • Pij is the numerical economic value assigned to that consequence.
    Consequence = a description of what happens.
    Payoff = the numerical value assigned to what happens.
    Generic 2 × 2 payoff table
    AlternativeS1S2
    A1P11P12
    A2P21P22

  5. Payoff construction · 2

    Reading Pij

    i identifies the selected alternative and therefore the row. j identifies the realized state and therefore the column. Thus P12 is the payoff when A1 is selected and S2 occurs.

    Direct payoffs
    S1S2
    A1104
    A278
    P11 = 10  ·  P12 = 4  ·  P21 = 7  ·  P22 = 8

    This is the simplest situation: the payoffs are already supplied directly, so no construction is needed.

  6. Payoff construction · 3

    Sometimes the payoff must be calculated

    Payoff = Variable payoff + Fixed payoff

    VARIABLE PAYOFF

    A per-unit value multiplied by qij. Quantity might count units, customers, products, contracts, shipments, or transactions.

    FIXED PAYOFF

    Added or subtracted independently of qij. “Fixed” means fixed with respect to quantity—not necessarily identical everywhere in the table.

    qij is the quantity for cell (Ai,Sj); it multiplies a variable rate and is not a fifth payoff component.

  7. Payoff construction · 4 · Reference

    What determines each payoff component?

    Alternative-based changes with the selected row; State-based changes with the realized column. “Both” means that the alternative-based and state-based components are simultaneously present.

    The four-component classification matrix
    Alternative-basedState-based
    VariableqijviAqijvjS
    FixedfiAfjS
    i → row / alternative dependent
    j → column / state dependent
    ij → potentially different in every cell
    qij has both indices because quantity may differ for every alternative–state pair.

  12. Classification checkpoint

    The four fundamental components

    Alternative-based variable
    qijviA
    State-based variable
    qijvjS
    Alternative-based fixed
    fiA
    State-based fixed
    fjS

    Variable clues

    Per unit, item, shipment, customer, or transaction; multiplied by a quantity.

    Fixed clues

    Lump sum, fixed cost or bonus, setup amount, or adjustment independent of quantity.

    Alternative-based clue

    The amount changes according to the selected decision.

    State-based clue

    The amount changes according to the realized uncertain condition.

    Classify before calculating. Any absent component is zero; not every problem uses all four.

  17. Synthesis

    From one component to four

    One component

    qijviA  or  qijvjS  or  fiA  or  fjS

    Two components

    Examples: qij(viA+vjS) or fiA+fjS. Other two-component subsets are valid.

    Three components

    Water Treatment: qij(viA+vjS)+fiA. Other three-component subsets are valid.

    Four components

    qij(viA+vjS)+fiA+fjS

    same structure+applicable component→greater detail

    Component count is not table size: four components does not mean four alternatives, four states, or a 4 × 4 table. Complexity increases by adding only the applicable payoff components.

  18. Reusable method

    How to solve payoff-construction problems

    1. Identify alternatives Ai.
    2. Identify the uncertain event.
    3. Identify states Sj.
    4. Identify each (Ai,Sj) consequence.
    5. Decide whether Pij is direct or calculated.
    6. Separate calculated information into Variable and Fixed payoff.
    7. For every component, decide whether it depends on Alternative (i) or State (j).
    8. Identify qij whenever a variable component is present.
    9. Write only the components that apply.
    10. Substitute values for each (i,j) pair.
    11. Calculate every Pij.
    12. Put alternatives in rows and states in columns.
    13. Check units and ensure every pair has exactly one payoff.
    Story→Identify components→Formula→Calculate Pij→Payoff table

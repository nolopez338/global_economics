  1. Introduction · Decision under uncertainty

    Local Café Investment

    A café must decide whether to launch a new line of artisan desserts or keep its current menu before it knows the actual foot traffic. The possible states are high traffic and low traffic. Each decision–traffic combination has different economic consequences: projected profits of 42 or 8 thousand USD for the dessert line, and 28 or 20 thousand USD for the current menu.

  2. Introduction · Decision elements

    Identify the four elements

    Café decision elements
    AlternativesLaunch dessert line; keep current menu
    States of NatureHigh traffic; low traffic
    EventActual foot traffic after the decision
    ConsequencesThe profit outcome produced by each alternative–state pair

    The decision-maker controls the alternative, but not which state the uncertain event produces.

  3. Introduction · Payoff table

    Organize every alternative–state pair

    Using the convention we will follow in class, alternatives form the rows and states of nature form the columns. Each cell holds one numerical payoff.

    Café profit (thousand USD)
    AlternativeHigh trafficLow traffic
    Launch dessert line428
    Keep current menu2820

  4. Payoff construction · 1

    From consequence to payoff

    Alternative \(A_i\)+State \(S_j\)→Consequence→Payoff \(P_{ay}(A_i,S_j)\)
    • The decision-maker selects \(A_i\).
    • The uncertain event determines which \(S_j\) occurs.
    • The pair \((A_i,S_j)\) produces a consequence.
    • \(P_{ay}(A_i,S_j)\) is the numerical economic value assigned to that consequence.
    Consequence = a description of what happens.
    Payoff = the numerical value assigned to what happens.
    Generic 2 × 2 payoff table
    Alternative\(S_1\)\(S_2\)
    \(A_1\)\(P_{ay}(A_1,S_1)\)\(P_{ay}(A_1,S_2)\)
    \(A_2\)\(P_{ay}(A_2,S_1)\)\(P_{ay}(A_2,S_2)\)

  5. Payoff construction · 2

    Two valid payoff-table orientations

    The payoff notation does not depend on where alternatives or states are placed in the table. \(P_{ay}(A_i,S_j)\) means the payoff produced by alternative \(A_i\) together with state \(S_j\), regardless of table orientation.

    Alternatives as rows

    \(S_1\)\(S_2\)
    \(A_1\)\(P_{ay}(A_1,S_1)\)\(P_{ay}(A_1,S_2)\)
    \(A_2\)\(P_{ay}(A_2,S_1)\)\(P_{ay}(A_2,S_2)\)

    Alternatives as columns

    \(A_1\)\(A_2\)
    \(S_1\)\(P_{ay}(A_1,S_1)\)\(P_{ay}(A_2,S_1)\)
    \(S_2\)\(P_{ay}(A_1,S_2)\)\(P_{ay}(A_2,S_2)\)

    Both presentations are valid. To keep our work consistent in class, we will use alternatives as rows and states of nature as columns.

    i identifies the alternative; j identifies the state. The indices identify function inputs, not a row or column by themselves.

  6. Payoff construction · 3

    Sometimes the payoff must be calculated

    \[\text{Payoff}=\text{Variable payoff}+\text{Fixed payoff}\]

    VARIABLE PAYOFF

    A per-unit value multiplied by \(q(A_i,S_j)\). Quantity might count units, customers, products, contracts, shipments, or transactions.

    FIXED PAYOFF

    Added or subtracted independently of \(q(A_i,S_j)\). “Fixed” means fixed with respect to quantity—not necessarily identical everywhere in the table.

    \(q(A_i,S_j)\) is the quantity for cell \((A_i,S_j)\); it multiplies a variable rate and is not a fifth payoff component.

  7. Payoff construction · 4 · Reference

    What determines each payoff component?

    Alternative-based changes with the selected alternative; State-based changes with the realized state. “Both” means that the alternative-based and state-based components are simultaneously present.

    The four-component classification matrix
    Alternative-basedState-based
    Variable\(q(A_i,S_j)v^A(A_i)\)\(q(A_i,S_j)v^S(S_j)\)
    Fixed\(f^A(A_i)\)\(f^S(S_j)\)
    \(A_i\) → alternative input
    \(S_j\) → state input
    \((A_i,S_j)\) → potentially different for every pair
    \(q(A_i,S_j)\) takes both the alternative and the state as inputs because quantity may differ for every alternative–state pair.

  12. Classification checkpoint

    The four fundamental components

    Alternative-based variable
    \(q(A_i,S_j)v^A(A_i)\)
    State-based variable
    \(q(A_i,S_j)v^S(S_j)\)
    Alternative-based fixed
    \(f^A(A_i)\)
    State-based fixed
    \(f^S(S_j)\)

    Variable clues

    Per unit, item, shipment, customer, or transaction; multiplied by a quantity.

    Fixed clues

    Lump sum, fixed cost or bonus, setup amount, or adjustment independent of quantity.

    Alternative-based clue

    The amount changes according to the selected decision.

    State-based clue

    The amount changes according to the realized uncertain condition.

    Classify before calculating. Any absent component is zero; not every problem uses all four.

  13. Two active components · Variable depends on both

    Recycling Collection Contract

    Alternatives: Electric, Diesel fleet. States: High, Low recovery.
    \(v^A(A_i)\): Electric 0.6, Diesel 0.4. \(v^S(S_j)\): High 0.3, Low 0.1.
    \(q(A_i,S_j)\): Electric 80,55; Diesel 95,65.

    The variable payoff depends on both because an alternative-based and a state-based per-unit contribution are simultaneously present.

    \(q(A_i,S_j)v^A(A_i)\) ✓

    \(f^S(S_j)\)

  17. Synthesis

    From one component to four

    One component

    \(q(A_i,S_j)v^A(A_i)\)  or  \(q(A_i,S_j)v^S(S_j)\)  or  \(f^A(A_i)\)  or  \(f^S(S_j)\)

    Two components

    Examples: \(q(A_i,S_j)\left(v^A(A_i)+v^S(S_j)\right)\) or \(f^A(A_i)+f^S(S_j)\). Other two-component subsets are valid.

    Three components

    Water Treatment: \(q(A_i,S_j)\left(v^A(A_i)+v^S(S_j)\right)+f^A(A_i)\). Other three-component subsets are valid.

    Four components

    \(q(A_i,S_j)\left(v^A(A_i)+v^S(S_j)\right)\)+\(f^A(A_i)+f^S(S_j)\)

    same structure+applicable component→greater detail

    Component count is not table size: four components does not mean four alternatives, four states, or a 4 × 4 table. Complexity increases by adding only the applicable payoff components.

  18. Reusable method

    How to solve payoff-construction problems

    1. Identify alternatives \(A_i\).
    2. Identify the uncertain event.
    3. Identify states \(S_j\).
    4. Identify each \((A_i,S_j)\) consequence.
    5. Decide whether \(P_{ay}(A_i,S_j)\) is direct or calculated.
    6. Separate calculated information into Variable and Fixed payoff.
    7. For every component, decide whether it is a function of the Alternative \(A_i\) or the State \(S_j\).
    8. Identify \(q(A_i,S_j)\) whenever a variable component is present.
    9. Write only the components that apply.
    10. Substitute values for each \((A_i,S_j)\) pair.
    11. Calculate every \(P_{ay}(A_i,S_j)\).
    12. Put alternatives in rows and states in columns.
    13. Check units and ensure every pair has exactly one payoff.
    Story→Identify components→Formula→Calculate \(P_{ay}(A_i,S_j)\)→Payoff table

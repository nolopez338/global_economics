The summary tables provide four statistics for each \GTenToneHL{alternative}{alternative}, all in thousand USD and rounded to two decimal places. Use these supplied statistics directly; you are not required to recalculate them from the \GTenToneHL{payoff}{payoff} matrices.
\begin{itemize}
\item \textbf{\GTenToneHL{best}{Maximax}:} select the highest Max Payoff (the \GTenToneHL{alternative}{alternative}'s maximum \GTenToneHL{payoff}{payoff}).
\item \textbf{\GTenToneHL{worst}{Maximin}:} select the highest Min Payoff (the \GTenToneHL{alternative}{alternative}'s minimum \GTenToneHL{payoff}{payoff}).
\item \textbf{\GTenToneHL{maxregret}{Minimax} \GTenToneHL{maxregret}{Regret}:} select the lowest Max Regret. Regret in each state is the best \GTenToneHL{payoff}{payoff} among all six original \GTenToneHL{alternative}{alternatives} in that state minus the \GTenToneHL{alternative}{alternative}'s \GTenToneHL{payoff}{payoff}; Max Regret is the largest of these regrets.
\item \textbf{\GTenToneHL{expected}{EMV} (\GTenToneHL{expected}{Expected} \GTenToneHL{expected}{Monetary} \GTenToneHL{expected}{Value}):} select the highest \GTenToneHL{expected}{EMV}, calculated using the stated \GTenToneHL{probability}{probabilities} as \GTenToneHL{payoff}{payoff} weights.
\end{itemize}
Apply each problem's filtering rules sequentially. Compare only \GTenToneHL{alternative}{alternatives} retained from the preceding stage; eliminated \GTenToneHL{alternative}{alternatives} cannot reenter. All original summary statistics remain fixed: do not recalculate any statistic after eliminating \GTenToneHL{alternative}{alternatives}. When asked to keep the best $k$ \GTenToneHL{alternative}{alternatives}, retain every \GTenToneHL{alternative}{alternative} tied at the cutoff, even if more than $k$ remain. At the final stage, report a tie explicitly if multiple \GTenToneHL{alternative}{alternatives} share the best value.

Represent each process in a four-column filtering table: \# Step, Description, Left Alternatives, and Eliminated Alternatives. Step 0 lists all six \GTenToneHL{alternative}{alternatives}. For each subsequent stage, record the criterion, filtering rule, relevant numerical values, and \GTenToneHL{alternative}{alternatives} retained or eliminated at that stage. Identify the final selected \GTenToneHL{alternative}{alternative} (or tied \GTenToneHL{alternative}{alternatives}) in the last row. The problems use two to four filtering stages and vary the criteria applied.

# Editing

[Highlights index](specific_highlights_index.md). LaTeX is authoritative.

Authoritative modules: [highlights.tex](highlights.tex), [specific_highlights.tex](specific_highlights.tex), [highlights_catalog.tex](highlights_catalog.tex).

1. Read the [routing table](specific_highlights_index.md), applicable repository instructions, target module and its live callers. LaTeX wins over these descriptions.
2. Change the smallest owner: rendering, palette, role, record, membership, table, adapter or viewer. Preserve questions, solutions and existing switch settings. Never insert wrappers into column specifications or spacing lengths such as `\\[4pt]`; use braced math arguments such as `\sqrt{\HLSampleSD{s}}`.
3. For an extension, declare a stable meaning ID only if new, then contexts with actual grade/term/all criteria, notation, variant, sources and available example interpretations. Add those context IDs to the intended reference and full reference. A prerequisite is not a new criterion table; unavailable references stay pending. See [declaration syntax](specific_highlights_catalog.md).
4. Check identity, source scope, units and context versus general definitions. Preserve success probability/population proportion, Poisson count/exponential rate and sample SD/standard error distinctions.
5. Use update-latex-complete: isolated compilation, diagnostics, mathematical review, every-page rendered inspection, navigation and representative consumer builds. Compare historical presentations before/after; test both toggle states and local palettes. Run `python book/preamble/highlights/tests/check_highlights.py` from the repository root and compile `tests/public_interfaces.tex` from the highlights directory into an isolated output directory. These check declarations, scoped union completeness, availability, historical keys, documentation links, loading, inherited fields, toggle retention, palette snapshots and forwarding. These checks do not replace rendered inspection.
6. Update only the affected family document; keep this guide/index short. Do not generate another catalog or overview, or recreate the removed proposal/monolithic summary.

An explicitly requested fast edit uses update-latex-fast and remains source-only: no compilation, rendering or verification claims. Complete verified updates require the full workflow and matching PDFs. Report exact coverage and unresolved limits; compilation alone does not prove visual equivalence.

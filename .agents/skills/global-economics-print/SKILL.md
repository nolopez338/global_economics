# Global Economics Classroom Print Activities

Use this skill for work students do during a lesson. Independent take-home practice and formal exams have their own authoring workflows.

1. Identify the lesson purpose, audience, supplied learning criteria, and print constraints. Read the [layout and build guide](references/template_print.md) and adapt a copy of the [LaTeX scaffold](assets/template_print.tex).
2. Choose the sequence that fits the lesson.
   - **Guided lesson.** Start with a visible activity title and the relevant learning criteria when supplied. Briefly introduce the method or notation, demonstrate it in a worked example, then move to guided tasks with partial scaffolding and in-class practice with fewer prompts. Include only the stages the lesson needs.
   - **Problem-first worksheet.** Put numbered contexts, data, and tasks on the student pages. When the brief calls for answers, start a Solutions section on a fresh page so the student pages can be printed separately.
3. Make each problem self-contained. State the givens, units, and constraints. Keep each data table or figure close to its task. Match the response space to the work expected using blank cells, partially completed tables, answer lines, or space for calculations or sketches.
4. Keep answers for unsolved tasks on the solution pages when included. Match the worksheet's problem numbers and task labels. Choose worked calculations, annotated tables, graphs, diagrams, or a compact answer table according to what students need to review. In a worked solution, connect the context to the model or method, show the intermediate reasoning, and interpret the result.
5. For graphs, follow the guide's graph workflow and check axes, units, labels, plotted values, and annotations against the problem and any solution. Compile and inspect the activity using the guide's print checks.

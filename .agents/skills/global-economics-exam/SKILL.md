# Global Economics Exam

1. Establish the grade, term, assessment designation and title, applicable teacher and school year, learning objective, and assessed criterion IDs and descriptions. Determine whether students answer on the sheet or on separate paper. Ask for missing grading or submission details when they affect the instructions.
2. Write self-contained questions with the givens, units, assumptions, and directions students need to calculate, construct, or justify their answers. Place each table or figure beside the task it supports. Solve each question privately to verify that the data are consistent and the requested result is well-defined. Check feasible domains, boundary cases, and ties where relevant. Keep solutions out of the student copy.
3. Assign points to each question by criterion. Mark separately scored tasks individually and roll their points up into the question heading. Build the score matrix from the final question list, including only assessed criteria. Reconcile every matrix entry and criterion total with the headings and scored tasks.
4. Adapt the [LaTeX scaffold](assets/template_exam.tex) using the [LaTeX and build guide](references/template_exam.md). Begin with the full-width institutional header and learning objective with the actual criteria. Include student identification when needed. Start the two-column body with **Criteria assessment**, then the score matrix and numbered questions. State what students must show and include only the supplied grading and submission policies. For any passing threshold, specify whether it uses points from this exam or cumulative points.
5. Reserve space where students write on the sheet, or tell students where to answer on separate paper. Build and inspect the PDF for the header and logo, continuous numbering, readable tables and figures, sensible column breaks, and sufficient workspace. Verify the final PDF's scores against the prompts and remove any remaining placeholders.

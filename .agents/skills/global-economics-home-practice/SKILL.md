# Global Economics Home Practice Activities

1. Identify the grade, term, topic, target difficulty, criterion IDs and descriptions, and any supplied tasks, data, or solution requirements. Use the criterion wording from the brief and ask for missing wording when it is essential. When adapting an activity, use the source supplied for that adaptation.
2. Start from the [LaTeX scaffold](assets/template_home_practice.tex) and use the [authoring guide](references/template_home_practice.md) for inputs, navigation, graphs, and builds. Replace the placeholders with the activity title, linked contents, and **Evaluated criteria**. List the actual IDs and descriptions and label nonconsecutive IDs explicitly.
3. Add a short introduction when students need definitions, notation, assumptions, or a reusable method. Use a general or symbolic worked example when it helps students apply the method to contextual problems.
4. Use one **Worked Solution Examples** section for a short activity. When several groups improve the progression, organize them by concept, method, or difficulty. Give each group a linked problem list and use numbered problem subsections. Make each scenario self-contained by supplying the information, units, and constraints students need for its criterion-linked tasks.
5. In each worked solution, connect the scenario to the mathematical model, state the rule or formula, show substitutions and intermediate reasoning, and interpret the result in context. Use equations, tables, graphs, or diagrams where they clarify the reasoning. Move from guided examples to more demanding applications when appropriate. Keep independent tasks distinct from worked examples and place their solutions where the brief calls for them.
6. Recalculate results and check that the tasks address the listed criteria. Follow the guide to compile and inspect the layout and the contents, problem, task, and return links. Check any graphs against the calculations and remove unused placeholders and inputs from the activity.

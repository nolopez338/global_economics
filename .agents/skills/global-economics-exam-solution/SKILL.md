# Global Economics Exam Solution

Read the [LaTeX and build guide](references/template_exam_solution.md) and adapt a copy of the [solution-key scaffold](assets/template_exam_solution.tex). Deliver an editable `.tex` file and compile its matching PDF when requested. The key should let a reader see each original question, its point value, and the reasoning that earns credit in one document.

1. **Establish the source.** Use the exam or assessment brief for this key, along with any supplied rubric. If companion TeX and PDF files are available, verify that the rendered content, numbering, figures, and marks match before treating the files as interchangeable. If they differ, establish which version governs or ask when the governing version is unclear.
2. **Set up the front matter.** Start with an exam solutions title, the linked contents with the `toc` anchor, the learning objective, criteria assessment instructions, and evaluated criteria, in that order. Use the actual criterion IDs, including gaps. Carry over the source grading policies and distinguish exam-only from cumulative passing thresholds when both apply.
3. **Reproduce the exam.** Use one scored section per source question. Preserve wording, order, numbering, subpart labels, context, data, figures, and point allocations. Put each original task before its corresponding solution. Flag any ambiguity, inconsistent data, or conflicting marks at the affected item, state any assumption used in the worked solution, and keep the original prompt intact.
4. **Complete and mathematically check all solutions.** Work every question and subpart before creating any new partial-credit allocations. Connect the givens to the method, show intermediate calculations or reasoning, and state the result with units and interpretation where applicable. Use completed tables, equations, graphs, or diagrams where they clarify the work. Check calculations, feasible domains, ties, and boundary cases when relevant.
5. **Create partial credit as the final authoring pass.** Only after ALL worked solutions are complete and mathematically checked, review each solution's actual reasoning and procedures against its assessed criterion. Identify observable assessable components and assign values within the source task's existing allocation, following the scoring decisions below. This is standard behavior, without a separate request. Create the rubrics at this stage, but insert each immediately after its corresponding worked task, before return navigation; follow the guide's presentation contract and scaffold example.
6. **Reconcile and verify the key.** Reconcile every row sum, subpart subtotal, task total, question total, criterion total, and overall total after creating the rubrics. Compare prompts, scored headings, solutions, and scoring notes with the governing exam or brief. Flag source inconsistencies rather than changing supplied totals to make them balance. Add a condensed answer summary only when requested, using the original question numbers and worked results. For a requested PDF, follow the build and inspection steps in the guide.

## Scoring decisions

- Preserve supplied official rubrics and marking policies; they take precedence over proposed subdivisions. Preserve all source task, question, criterion, and overall totals. Clearly identify any newly proposed subdivision, including one within an official allocation, without replacing or contradicting official components.
- Derive rows from the completed solution and assessed criterion, not generic rubric rows. Weight components by mathematical significance and work required, using simple exact values where practical. Do not award the same work twice or add requirements absent from the task.
- Support valid alternative methods and consistent follow-through after arithmetic errors, subject to supplied marking policy. Credit demonstrated mathematical work rather than requiring the key's particular route.
- Respect explicit scoring exclusions. Keep explanatory checks carrying no points separate from assessed components; do not make them implicit conditions for credit.
- Generalize the presentation across grades, terms, topics, and criteria. Example content, criterion IDs, point values, and exam-specific exclusions are not universal scoring rules.

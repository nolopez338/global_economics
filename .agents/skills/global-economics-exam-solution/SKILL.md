# Global Economics Exam Solution

Read the [LaTeX and build guide](references/template_exam_solution.md) and adapt a copy of the [solution-key scaffold](assets/template_exam_solution.tex). Deliver an editable `.tex` file and compile its matching PDF when requested. The key should let a reader see each original question, its point value, and the reasoning that earns credit in one document.

1. **Establish the source.** Use the exam or assessment brief for this key, along with any supplied rubric. If companion TeX and PDF files are available, verify that the rendered content, numbering, figures, and marks match before treating the files as interchangeable. If they differ, establish which version governs or ask when the governing version is unclear.
2. **Set up the front matter.** Start with an exam solutions title, the linked contents with the `toc` anchor, the learning objective, criteria assessment instructions, and evaluated criteria, in that order. Use the actual criterion IDs, including gaps. Carry over the source grading policies and distinguish exam-only from cumulative passing thresholds when both apply.
3. **Reproduce the exam.** Use one scored section per source question. Preserve wording, order, numbering, subpart labels, context, data, figures, and point allocations. Put each original task before its corresponding solution. Flag any ambiguity, inconsistent data, or conflicting marks at the affected item, state any assumption used in the worked solution, and keep the original prompt intact.
4. **Work every question and subpart.** Connect the givens to the method, show intermediate calculations or reasoning, and state the result with units and interpretation where applicable. Use completed tables, equations, graphs, or diagrams where they clarify the work. Check feasible domains, ties, and boundary cases when relevant.
5. **Reconcile the scoring.** Check marks in the original prompts, scored headings, worked solutions, and scoring notes against the source subpart and criterion totals and the overall total where supplied. Use the supplied rubric for mark-by-mark and partial-credit guidance. Label any newly requested scoring breakdown as proposed. Add a condensed answer summary only when requested, using the original question numbers and results from the worked sections.
6. **Verify the key.** Compare the completed source with the governing exam or brief. For a requested PDF, follow the build and inspection steps in the guide.
